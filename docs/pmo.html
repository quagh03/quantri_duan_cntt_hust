4. Quy tắc PMO

  1. Tách bạch: Doc 1 = kiểm soát giai đoạn · Doc 2 = nhân sự nội bộ · Doc 3 = phản hồi stakeholder · Doc 4 = đóng dự án · Doc 5 = lessons.
  2. Evidence-based: không Pass gate nếu thiếu cột Bằng chứng.
  3. Conditional Pass luôn có action item (owner + due) trên Jira epic GATE.
  4. Peer raw không đưa vào E-HSDT / không gửi khách hàng; Doc 5 chỉ nhận synthesis/theme.
  5. Lesson chưa vào OPA = chưa học xong; Closure §9 chỉ Keep/Improve/Try — chi tiết ở E.5.
