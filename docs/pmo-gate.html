Hướng dẫn điền (rút gọn)
  1. PM mở checklist gate ≥ 3 ngày làm việc trước họp exit review (60–90 phút).
  2. Mỗi dòng: điền Bằng chứng; Status = Đạt / Chưa đạt / N/A. ★ = bắt buộc để Pass.
  3. Quyết định: Pass · Conditional Pass (mỗi điều kiện = 1 action item) · Fail.
  4. Không dùng để đánh giá nhân sự; không thay phản hồi stakeholder.
  5. Action items Conditional bắt buộc ticket Jira epic GATE-Gx.
  6. In: mặc định chỉ in gate đang chọn (bỏ tick để in cả bộ).
